# muse4ai-zh
Muse4AI 是一款通过 Muse 生成图片和视频的 Windows 软件，但界面只有英文和越南语。

这个补丁把它的中文界面补齐了：约 2480 条界面文字全部翻译，包括托盘菜单、系统通知和内置的使用指南。原理是替换程序里「越南语 → 英文」的翻译词典，再把语言固定到中文那一侧，所以不需要改源码，也不影响软件功能。

使用很简单：完全退出软件，双击 install.cmd，再打开就是中文。之后软件每次更新，后台任务会在你退出软件后自动重新汉化，不用再手动操作。原始文件会备份成 app.asar.orig，运行 uninstall.cmd 即可完全还原。

补丁只修改本机的程序文件，不上传任何数据，也不绕过 Muse 的额度或地区限制。属于非官方项目，与软件作者无关。
一键安装：双击即可，不需要管理员权限，不用装任何额外环境
更新免维护：新版本退出后自动汉化，下次打开就是中文
安全可逆：只改本机程序文件，原文件有备份，一键还原
覆盖全面：界面 + 托盘 + 通知 + 内置指南，约 2480 条
